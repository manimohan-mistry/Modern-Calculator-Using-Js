✨ Animated Calculator

A modern, animated calculator built with HTML, CSS, and JavaScript, featuring glassmorphism and smooth UI interactions.

🚀 Features

Glassmorphism UI with frosted-glass effect

Smooth animations on every interaction

Live expression preview (e.g., 5 + 3)

Ripple & sparkle effects on button press

Glowing display with shimmer animation

Responsive design for all screen sizes

Keyboard support (numbers, operators, Enter, Escape)

🎨 UI Highlights

Gradient backgrounds with floating circles

Animated hover effects

Pulsing "=" button

Shimmering display

Clean, minimal layout

🛠️ Tech Stack

HTML5

CSS3 (glassmorphism, gradients, animations)

Vanilla JavaScript
